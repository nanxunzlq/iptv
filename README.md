## 使用方法

1. 获取直播源地址（Raw 链接）：

   ```
   https://raw.githubusercontent.com/nanxunzlq/iptv/main/hn.txt
   ```

2. 在播放器中添加该地址，即可自动导入全部频道。支持的播放器包括：

   - **DIYP / 影视类应用**：在「直播配置/接口」中填入上述地址
   - **PotPlayer**：右键 → 打开 → 打开链接
   - **TiviMate / IPTVnator**：新建播放列表 → 选择远程 URL

   也可以直接下载 `hn.txt` 本地导入。
