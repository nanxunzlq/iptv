### 匹配口径

1. **基准单位**：移动源按频道名去重（`·备用线路N` 后缀剥离），得 132 个唯一频道；条数统计仍按 283 条原始条目计算。
2. **判定顺序**：源内同名 → 编号写法归一（`CCTV-1综合` 的 `tvg-name` 为 `CCTV1`，与移动 `CCTV1` 一致）→ 别名表（CETV1、省略“频道”二字、去地域前缀、4K 试验频道）。
3. **保守原则**：名称相近但频道定位不同的不强行配对，例如移动「河南移动电视」与电信「移动戏曲」、移动「河南梨园」与电信「河南戏曲」均未互认，已在缺失表中注明。
4. **一对多**：`收藏天下` 在移动源中被两个分组重复收录，对照表中出现两行，电信侧只占一条。
